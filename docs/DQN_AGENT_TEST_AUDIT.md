# DQN agent regression-test audit

**Purpose:** Add fast automated checks for core DQN mechanics before further training. These tests do not train a harbour policy and do not use evaluation episode seeds.

## Checks added

1. Online and target networks start with identical parameters.
2. Terminal transitions do not bootstrap from the next-state Q-value.
3. Nonterminal transitions do bootstrap from the target network.
4. Target-network synchronization occurs at the configured gradient-step interval.
5. Replay memory stores copies of observations and respects its configured capacity.

## Result

`python -m pytest -q`: **16 passed** (11 existing environment tests and 5 new agent tests).

## Scope and limitations

These are focused regression tests for the mechanics exercised by the current implementation. They do not establish that DQN will learn a good policy, prove the historical checkpoint was generated by byte-identical source, or explain the observed seed sensitivity. No production algorithm code, reward parameters, checkpoint, or training configuration was changed.
